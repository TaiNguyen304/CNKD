TRIỂN KHAI RENDER (NODEJS / SERVER.JS)

Dự án được viết hoàn toàn bằng NodeJS nguyên bản (server.js), không dùng Typescript theo đúng yêu cầu.

Start Command: npm start hoặc node server.js
1. Đẩy lên Github / Render Kết nối repository của bạn với Render.com (chọn Web Service).
2. Cấu hình Runtime Môi trường: Node. Build Command: npm install.
3. Lệnh khởi chạy Start Command: node server.js (tự động nhận PORT của Render).
